# 产品竞品调研报告模板

产品竞品调研的完整报告结构。其他调研类型可裁剪或扩展章节。

## 报告骨架

根据调研主题选择结构模式：

- **模式A（地域驱动）**：适用于"某个市场有哪些玩家"类调研，按国内/海外分章
- **模式B（场景驱动）**：适用于"某能力在不同场景下表现如何"类调研，先定义能力维度再按应用场景逐一拆解。完整骨架和厂商逐一评估模板见 `research-types.md` 竞品调研执行要点

### 模式A：地域驱动结构

适用于"某个市场有哪些玩家"类调研，按国内/海外分章。核心章节骨架：
```
一、调研框架总览        → 覆盖维度一览
二、市场与行业背景      → 市场规模/驱动力/技术演进
三、国内产品图谱        → 云厂商 + 专精型企业，含能力矩阵
四、海外产品图谱        → 云厂商 + 传统厂商 + 新兴工具，含能力矩阵
五、垂类行业场景        → 按行业拆解应用场景和代表产品
六、核心差异深度分析    → 定位/技术路线/交付模式三维对比
七、技术趋势与洞察      → 方向研判
八、竞争格局与核心发现  → 梯队划分 + 精炼结论
```

> **注**：报告中不包含"修订记录"节——最终交付的始终是最新干净版本，修订过程在对话中沟通，不写入文件正文。

## 单产品信息表格

每个产品使用统一维度表格，便于横向对比：

```markdown
> 来源：[产品官网](URL)、[API文档](URL)

| 维度 | 详情 |
|------|------|
| **产品名** | {官方名称} |
| **核心能力** | {主要功能点} |
| **特色能力** | ① {差异化功能1} ② {功能2} ③ {功能3} |
| **输出格式** | {支持的格式} |
| **部署方式** | {公有云/私有化/SDK等} |
| **计费模式** | {计费方式：按次/按页/按Token/按积分等} |
| **定价** | {具体定价，必须来自官方定价页} |
| **核心差异** | **{加粗关键差异}**，补充说明 |
```

**定价字段填写规范**（核查流程详见 SKILL.md"定价数据核查强规则"）：
- 必须通过 `web_fetch` 访问官方定价页获取，不得引用第三方媒体或搜索摘要
- 标注计费单位（按次/按页/按Token/按积分）
- 有Batch/批量折扣的单独列出
- 免费额度单独列出（时间/数量/条件）
- 区域定价差异的标注各区域价格
- 私有化或大客户价格，如实标注"需联系商务"

## 能力矩阵表格

汇总对比使用 ✅/❌/部分/未明确 标注，配合脚注：

```markdown
| 厂商 | 能力A | 能力B | 能力C | 能力D |
|------|:---:|:---:|:---:|:---:|
| 产品1 | ✅ | ✅ | ❌ | ✅ |
| 产品2 | ✅ | 部分¹ | ✅ | 未明确 |

> ¹ 脚注解释"部分"的具体含义
```
