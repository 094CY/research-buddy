# 战略分析工具集

当调研需要从"事实"推导到"策略"时，加载本文件。提供竞争定位、差距识别、机会推导、行动建议的结构化分析框架。

> 本文件不使用SWOT——SWOT优劣势分析过于主观和粗粒度，缺乏量化对比和行动推导能力。以下框架追求：可量化、可推导、可行动。

## 一、竞争定位分析

### 波特五力模型

评估行业竞争结构，判断行业吸引力和利润池分布：

```
          新进入者威胁
              ↑
  供应商 ──→ 行业竞争结构 ←── 买方
  议价力         │          议价力
                ↓
          替代品威胁
```

```markdown
| 五力维度 | 评估 | 依据 |
|---------|------|------|
| **新进入者威胁** | {高/中/低} | {壁垒分析：技术/资金/渠道/数据/牌照} |
| **供应商议价力** | {高/中/低} | {供应商集中度、切换成本、替代输入} |
| **买方议价力** | {高/中/低} | {客户集中度、切换成本、价格敏感度} |
| **替代品威胁** | {高/中/低} | {替代方案、转换意愿、转换成本} |
| **同业竞争强度** | {高/中/低} | {竞争者数量/差异化程度/退出壁垒} |
```

五力综合判断：**行业吸引力 = 高进入壁垒 + 低替代威胁 + 低买方议价力 + 低供应商议价力 + 适度同业竞争**。

### 竞争定位矩阵

二维象限定位，选择最能区分差异的两个维度：

**常见维度组合：**

| 行业场景 | X轴 | Y轴 |
|---------|-----|-----|
| 文档智能 | 广度（场景覆盖） | 深度（还原精度） |
| 云服务 | 技术领先度 | 生态完整度 |
| SaaS | 产品功能 | 服务能力 |
| 通用 | 价格竞争力 | 差异化程度 |

**输出示例：**

```
                    差异化程度
                        高
                         │
       象限D             │           象限A
    高差异化·高价格       │       高差异化·低价格
    （利基专家）          │       （最佳选择）
                         │
  ───────────────────────┼──────────────────────────
                         │
       象限C             │           象限B
    低差异化·高价格       │       低差异化·低价格
    （被动溢价）          │       （价格竞争者）
                         │
                        低
           低 ←─────────┼──────────→ 高
                    价格竞争力
```

每个产品标注在象限中的位置，并用1-2句话解释定位逻辑。

## 二、差距分析

量化自身产品与竞品的多维差距，找出关键短板和优势锚点。

### 多维差距雷达

选择5-8个核心维度，自身与标杆对标：

```markdown
| 维度 | 权重 | 自身产品 | 标杆产品 | 差距值 | 差距等级 |
|------|:---:|:---:|:---:|:---:|---------|
| 核心精度 | 25% | 6 | 9 | -3 | 🔴 关键短板 |
| 场景覆盖 | 20% | 7 | 8 | -1 | 🟡 待提升 |
| 输出格式 | 15% | 4 | 8 | -4 | 🔴 关键短板 |
| 部署灵活 | 15% | 5 | 7 | -2 | 🟡 待提升 |
| 生态集成 | 10% | 8 | 6 | +2 | 🟢 优势 |
| 行业方案 | 10% | 3 | 8 | -5 | 🔴 关键短板 |
| 定价竞争力 | 5% | 7 | 5 | +2 | 🟢 优势 |

| 综合加权得分 | 自身: 5.75 | 标杆: 7.55 | 差距: -1.80 |
```

差距等级规则：
- 🔴 关键短板（差距 ≥ 3 或 加权差距 ≥ 1.5）：影响核心竞争力，需优先补强
- 🟡 待提升（差距 1-2）：有改进空间，短期可追赶
- 🟢 优势（差距为正）：自身超出标杆的维度

**差距分析结论模板**：
```
关键短板：{最多3项，按优先级排序}
  → 短板1：{描述}，建议：{弥补路径}
  → 短板2：{描述}，建议：{弥补路径}

优势锚点：{自身超出竞品的维度，可作为差异化竞争点}
  → 优势1：{描述}，利用方式：{策略}
  → 优势2：{描述}，利用方式：{策略}

追赶优先级：先补{关键短板}，再提{待提升}，守住{优势}
```

## 三、机会识别

从市场空白、技术趋势、客户痛点三条路径推导机会。

### 机会矩阵

```markdown
                    实现可行性
                        高
                         │
           收获区         │         明星区
    （高吸引力·低可行性）  │    （高吸引力·高可行性）
                         │
  ───────────────────────┼──────────────────────────
                         │
           放弃区         │         过渡区
    （低吸引力·低可行性）  │    （低吸引力·高可行性）
                         │
                        低
           低 ←─────────┼──────────→ 高
                    机会吸引力
```

**机会评估维度：**

| 维度 | 评估方法 |
|------|---------|
| **机会吸引力** | 市场规模、增速、利润率、战略价值 |
| **实现可行性** | 技术可行性、资源需求、时间周期、组织匹配度 |

**每个机会条目：**

```markdown
| 机会 | 吸引力 | 可行性 | 象限 | 说明 |
|------|:---:|:---:|:---:|------|
| {机会1} | 高 | 高 | 明星 | {说明：为什么是机会、为什么可行} |
| {机会2} | 高 | 低 | 收获 | {说明：值得长期布局，但短期资源不足} |
| {机会3} | 低 | 高 | 过渡 | {说明：容易做但价值有限，可作为短期营收} |
```

### 蓝海战略画布（价值曲线对比）

当调研目的是"寻找差异化定位"时使用。画出各竞品的价值曲线，找到被忽视的竞争维度：

```markdown
| 竞争维度 | 产品A | 产品B | 产品C | **自身产品** | 蓝海机会 |
|---------|:---:|:---:|:---:|:---:|---------|
| 维度1（传统重视） | 高 | 高 | 高 | 中 | 可降低→释放资源 |
| 维度2（传统重视） | 高 | 中 | 高 | 中 | 可降低→释放资源 |
| 维度3（被忽视） | 低 | 低 | 低 | 高 | **创造差异化** ← |
| 维度4（被忽视） | 无 | 无 | 无 | 有 | **创造新赛道** ← |
```

**使用方式**：
1. 列出行业内传统竞争维度和被忽视维度
2. 评估各家在各维度的高低
3. 找到"降低哪些传统维度 + 创造哪些新维度"的组合
4. 这就是蓝海策略的核心——**差异化而不是更好**

## 四、价值链分析

定位行业利润池，判断自身在价值链中的位置和利润分配能力。

### 价值链拆解

```markdown
| 价值环节 | 代表企业 | 价值占比 | 利润率 | 进入壁垒 |
|---------|---------|:---:|:---:|---------|
| 上游：数据/标注 | {企业} | {X}% | {高/中/低} | {壁垒描述} |
| 中游：核心算法/引擎 | {企业} | {X}% | {高/中/低} | {壁垒描述} |
| 中游：行业解决方案 | {企业} | {X}% | {高/中/低} | {壁垒描述} |
| 下游：集成/分销 | {企业} | {X}% | {高/中/低} | {壁垒描述} |
| 下游：终端客户 | {企业} | {X}% | {高/中/低} | {壁垒描述} |
```

**关键洞察推导**：
- 利润集中在哪里？（利润池定位）
- 自身处于价值链哪个环节？利润捕获能力如何？
- 向价值链哪个方向移动可以捕获更多利润？
- 是否存在"微笑曲线"效应（两端高利润、中间低利润）？

## 五、竞争演进推演

```markdown
| **价格走势** | {现状} | {趋势} | {趋势} | {依据} |
| **新兴变量** | — | {可能出现的颠覆因素} | {可能出现的颠覆因素} | {依据} |
```


## 六、行动建议推导

从分析到决策的桥梁。基于以上分析，推导具体的、可操作的建议。

### 建议分层

```markdown
### 速赢行动（0-3个月）
1. **{行动项}**：{描述} → 预期效果：{量化预期}
2. **{行动项}**：{描述} → 预期效果：{量化预期}

### 战略举措（3-12个月）
1. **{行动项}**：{描述} → 依赖条件：{条件}
2. **{行动项}**：{描述} → 依赖条件：{条件}

### 长期布局（12个月+）
1. **{行动项}**：{描述} → 前提假设：{假设}
2. **{行动项}**：{描述} → 前提假设：{假设}
```

### 投入优先级矩阵

```
                    影响力
                        高
                         │
           优先做          │         必须做
    （低投入·高影响）       │    （高投入·高影响）
                         │
  ───────────────────────┼──────────────────────────
                         │
           可以做          │         以后做
    （低投入·低影响）       │    （高投入·低影响）
                         │
                        低
           低 ←─────────┼──────────→ 高
                    投入成本
```

**每条建议标注**：投入成本（低/中/高）、预期影响（低/中/高）、时间窗口、依赖条件/前提假设。

## 框架选择指引

| 调研目的 | 推荐框架 |
|---------|---------|
| 了解行业竞争结构 | 波特五力 + 竞争定位矩阵 |
| 自身产品对标找差距 | 多维差距雷达 + 行动建议 |
| 寻找差异化定位 | 蓝海战略画布 + 机会矩阵 |
| 评估行业利润分布 | 价值链分析 |
| 制定产品策略 | 差距分析 + 机会矩阵 + 行动建议 |
| 全面战略评估 | 以上全部 |

以上框架可组合使用，根据调研目的灵活选择，不必每次全部执行。
